# МЕД77: сайт перевозки лежачих больных

Статический одностраничный сайт без сборки: `index.html` + `css/style.css` + `js/main.js`.
Чтобы посмотреть локально, откройте `index.html` в браузере или запустите `python3 -m http.server` и зайдите на http://localhost:8000.

## Структура страницы

1. Шапка: телефон, «Работаем 24/7», кнопка расчёта
2. Первый экран: оффер, 3 пункта доверия, «Рассчитать» / «Позвонить», мессенджеры, цена «от»
3. Полоса цифр (24/7, подача, вся РФ, без доплат)
4. Калькулятор-заявка: маршрут → доп. услуги → ориентировочная цена → телефон
5. Услуги и цены (4 карточки) + доп. услуги
6. CTA-полоса «Нужна перевозка прямо сейчас?»
7. 5 шагов перевозки
8. Оснащение машины (галерея фото)
9. Почему МЕД77 (6 преимуществ)
10. Отзывы с Яндекс Карт
11. Гарантии
12. FAQ
13. Контакты: карта, форма
14. Подвал: реквизиты, лицензия, предупреждение «не скорая помощь»

На мобильных внизу появляется липкая панель «Позвонить 24/7 / WhatsApp».

## Заглушки, которые нужно заменить

| Что | Где |
|---|---|
| Телефон, Telegram, WhatsApp, MAX | `js/main.js` → `CONFIG` (подставляется на всю страницу) и для SEO в `index.html` (`+7 (929) 626-00-00`, `+79296260000`, `t.me/med77_placeholder`) |
| Цены в калькуляторе | `js/main.js` → `CONFIG.prices` |
| Цены в карточках услуг, доп. услугах и FAQ | `index.html`, разделы `#services` и `#faq` |
| Куда приходят заявки | `js/main.js` → `CONFIG.formEndpoint` (пока заявка открывается сообщением в WhatsApp) |
| Оценка на Яндекс Картах | `index.html`, раздел `#reviews` (комментарий `ЗАГЛУШКА`) |
| Фото машины, салона, носилок, команды | блоки `.ph` в `index.html` (заменить на `<img>`) |
| ООО, ИНН, ОГРН, номер лицензии | подвал `index.html` и `policy.html` |
| Текст политики конфиденциальности | `policy.html` (согласовать с юристом) |

Утверждения, которые стоит проверить: «подача от 60 минут», «перезвоним за 5 минут», «смена водителей в пути», бесплатные кресло-коляска и помощь с вещами, способы оплаты (наличные / карта / счёт).

Найти все заглушки в коде: `grep -rn "ЗАГЛУШКА\|626-00-00\|79296260000\|placeholder\|0000000000" .`
